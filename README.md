# Fast Food Order Customer Support Chatbot

An AI-powered customer service chatbot built for **Fast Food Order**, developed using **OpenAI GPT** and **Streamlit**.  
This chatbot interacts with customers, answers menu and delivery questions, and even helps take pizza orders conversationally!

---

## 🚀 Features

✔️ **Smart Customer Support** — Understands customer questions like deals, types of pizzas, crust options, delivery time, etc.  
✔️ **Order Assistance** — Guides users in placing pizza orders politely and professionally.  
✔️ **24/7 Chat Support** — Always available to answer questions, greet customers, and assist politely.  
✔️ **Friendly Pizza Expert** — Responds like a real pizza shop assistant with a warm tone.  
✔️ **Maintains Conversation History** — Remembers previous messages within a session for contextual replies.  
✔️ **Simple & Fast UI** — Built with Streamlit; no backend server required!

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **Python** | Programming language |
| **Streamlit** | Web UI for chatbot |
| **OpenAI GPT (gpt-4o-mini)** | Language model for customer support replies |
| **dotenv** | Secure API key loading |
| **OpenAI Python SDK** | To communicate with GPT API |
